# Emne 8 — Dual-use, forskning, teknologi og samfundsansvar

## Litteratur

### [[AnalyseForskningsTeknologiomDualUse.pdf]]

source:: COWI & SDU, “Analyse af forsknings- og teknologiområder”, udarbejdet for Danmarks Erhvervsfremmebestyrelse, maj 2023  
type:: analyserapport / erhvervs- og teknologipolitik  
keywords:: [[andre 1#dual-use|dual-use]], [[andre 1#forsknings- og teknologiområder|forsknings- og teknologiområder]], [[andre 1#forsvar|forsvar]], [[andre 1#rum og sikkerhed|rum og sikkerhed]], [[02_Emne_2_Datalogi_KI_og_robotteknologi|AI]], [[08_Etik_i_ingenioerarbejde|robotter]], [[andre 1#droner|droner]], [[andre 1#kvanteteknologi|kvanteteknologi]], [[02_Emne_2_Datalogi_KI_og_robotteknologi|big data]], [[andre 1#sektorkobling|sektorkobling]]

- Hovedtema: rapporten kortlægger danske forsknings- og teknologiområder og deres betydning for erhvervsliv, innovation og fremtidig erhvervsfremme.
- Rapporten er udarbejdet for Erhvervsstyrelsen/Danmarks Erhvervsfremmebestyrelse i samarbejde mellem COWI og SDU’s Center for Bæredygtig Erhvervsfremme.
- Rapporten bruges som beslutningsgrundlag for, hvilke erhvervs- og teknologiområder Danmark skal satse på.
- Fokus ligger ikke kun på vækst og innovation, men også på risici, importafhængigheder, værdikæder, geopolitiske forandringer og sikkerhed.
- Centrale teknologiområder i rapporten:
    - [[andre 1#digitale teknologier|digitale teknologier]]
    - [[andre 1#robot- og droneteknologi|robot- og droneteknologi]]
    - [[andre 1#kvanteteknologi|kvanteteknologi]]
    - [[andre 1#rumteknologi|rumteknologi]]
    - [[andre 1#forsvar, rum og sikkerhed|forsvar, rum og sikkerhed]]
    - [[02_Emne_2_Datalogi_KI_og_robotteknologi|AI]]
    - [[02_Emne_2_Datalogi_KI_og_robotteknologi|big data]]
- Dual-use betyder, at en teknologi kan bruges både civilt og militært.
- Rapporten nævner, at flere teknologier, der anvendes i krig, sikkerhed og forebyggelse, oprindeligt er udviklet civilt. Eksemplerne er AI, robotter/droner, quantum computing, rumforskning og big data.
- Vigtig pointe: grænsen mellem civil teknologi og militær teknologi bliver mere uklar.
- Et civilt udviklet dronesystem kan bruges til landbrug, redning eller inspektion — men også til overvågning, måludpegning eller våbenbrug.
- AI kan bruges til sundhed, logistik og energistyring — men også til autonome våben, cyberangreb, misinformation og militær analyse.
- Kvanteteknologi kan bruges til forskning, sensorer, kommunikation og beregning — men også til militær kapacitet og sikkerhedspolitisk magt.
- Rapporten lægger vægt på [[andre 1#sektorkobling|sektorkobling]]: teknologier opfundet i én sektor kan overføres til andre sektorer. Det gælder fx it, droner, energieffektive teknologier, robotteknologi og kvanteteknologi.
- Sektorkobling er både en styrke og en risiko:
    - styrke: viden kan skabe innovation på tværs af brancher
    - risiko: teknologi kan få anvendelser, som udviklerne ikke oprindeligt havde tænkt
- Rapporten peger også på behovet for at integrere humaniora og samfundsvidenskab med teknisk og naturvidenskabelig forskning. Begrundelsen er, at teknologiske udfordringer og risici ofte er samfundsmæssige og holistiske, ikke kun tekniske.
- Det er en meget vigtig eksamenspointe: dual-use kan ikke håndteres med teknik alene.
- Man skal også tænke på:
    - etik
    - jura
    - geopolitik
    - sikkerhed
    - menneskerettigheder
    - magt
    - misbrug
    - ansvar
- Rapporten passer godt sammen med Emne 7 om ingeniøretik, fordi den viser, at ingeniørens arbejde kan indgå i større systemer, som rækker langt ud over den oprindelige tekniske opgave.
- Den passer også med Emne 5 om Manhattanprojektet: naturvidenskabelig og teknisk viden kan bevæge sig fra forskning til militær anvendelse.
- Forskellen er, at Emne 8 handler om nutidens mere diffuse dual-use-problemer, hvor teknologien ofte starter som civil innovation.
- God eksamenspointe: I dag er faren ikke kun hemmelige våbenprogrammer, men almindelige teknologier, som kan skifte kontekst.

eksamen_vinkel:: Brug teksten til at diskutere, hvordan moderne forskning og teknologi bliver politisk og etisk kompleks, fordi samme teknologi kan skabe både samfundsnytte og skade. Dual-use viser, at ingeniører og forskere ikke kun bør spørge “kan vi bygge det?”, men også “hvem kan bruge det, hvordan kan det misbruges, og hvilke systemer bliver det en del af?”

## Centrale begreber

### [[andre 1#dual-use|dual-use]]

- Teknologi med dobbelt anvendelse.
- Kan bruges civilt og militært.
- Eksempler:
    - [[andre 1#droner|droner]]: landbrug, inspektion, redning / overvågning, krig, våbenplatforme.
    - [[02_Emne_2_Datalogi_KI_og_robotteknologi|AI]]: medicinsk diagnose, produktivitet / misinformation, cyberangreb, autonome våben.
    - [[andre 1#kvanteteknologi|kvanteteknologi]]: forskning, kommunikation / militær sensing, kryptografisk trussel.
    - [[andre 1#satellitter|satellitter]]: vejr, navigation, kommunikation / militær overvågning og måludpegning.

### [[andre 1#sektorkobling|sektorkobling]]

- Når teknologi eller viden flyttes mellem sektorer.
- Civil teknologi kan blive militær.
- Militær teknologi kan senere blive civil.
- Giver innovation, men gør ansvar mere komplekst.

### [[andre 1#teknologisk ansvar|teknologisk ansvar]]

- Ansvar handler ikke kun om intention.
- En teknologi kan få konsekvenser, udvikleren ikke ønskede.
- Jo mere forudsigelig risikoen er, desto sværere er det at fraskrive sig ansvar.
- Dual-use kræver risikovurdering, ikke bare teknisk optimering.

### [[andre 1#videnbroer|videnbroer]]

- Rapporten bruger idéen om forbindelser mellem forskning, teknologi og erhverv.
- Viden skal bevæge sig fra forskningsmiljøer til virksomheder og samfund.
- Kritisk vinkel: når viden flyder mere frit, kan den også lettere misbruges.

## Mulig eksamensformulering

Emne 8 kan handle om, at moderne teknologi sjældent er entydigt civil eller militær. Rapporten viser, at teknologier som AI, droner, robotter, kvanteteknologi, big data og rumteknologi kan skabe vækst og innovation, men også indgå i forsvar, overvågning og krigsførelse. Begrebet [[andre 1#dual-use|dual-use]] gør derfor ingeniørens ansvar mere komplekst: man udvikler måske en civil teknologi, men den kan senere bruges i en militær eller skadelig sammenhæng. Rapportens pointe om sektorkobling viser, at teknologi bevæger sig på tværs af brancher og formål. Derfor kræver moderne teknologivurdering ikke kun teknisk ekspertise, men også samfundsfaglige, humanistiske, etiske og sikkerhedspolitiske perspektiver.
